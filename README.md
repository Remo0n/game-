# Bento Blocks

A cozy puzzle game: slice blocks, arrange the pieces, and fill the bento tray.
Built with Expo, React Native, and Expo Router.

## Run

Use Node.js 22 or newer, then:

```sh
npm install
npm start
```

Scan the QR code with a compatible Expo Go app, or press `i` / `a` for an installed
simulator. For a browser preview:

```sh
npm run web
```

React and React DOM are pinned to the same version to keep npm peer dependencies
compatible. Web support is included.

## Play

- Choose **Play level** from the kitchen.
- In **Cut**, start anywhere on the cutting board and swipe across a piece along a grid seam. The guide previews the first valid cut your swipe crosses.
- Switch to **Move** and drag pieces into the tray. Tap a piece before rotating.
- Fill every square. Undo is free; hints and special tools affect your score.
- Completed levels and stars are saved automatically. Replays start fresh.

The home, gameplay, daily challenge, worlds, collection, settings, and results
share a responsive cream-and-matcha theme, locally bundled Outfit fonts, SVG
bento artwork, and consistent rounded icons. A small knife follows cut gestures;
the preview highlights only the intersected seam, with no line tethered to the
initial press.
The generator inspector remains available under Settings in development builds.

A skippable 2.2-second bento splash appears on a fresh launch (including web
refreshes and deep links). Pieces lift, split, spring into the tray, and move back
on undo; rotation, buttons, progress, and reward stars animate too. Animations
respect the device’s reduced-motion setting.

The native launch image is configured with `expo-splash-screen`. Rebuild the
native app after changing it; Expo Go does not reproduce the standalone native
splash. The animated in-app splash works in the browser and Expo Go.

## Check

```sh
npm run typecheck
npm test
npx expo export --platform web
```

The campaign teaches one mechanic per chapter, alternates challenges with easier
puzzles, and keeps timers in the optional Lunch rush mode. See
[DIFFICULTY_PROGRESSION.md](./DIFFICULTY_PROGRESSION.md) for the research,
curriculum, generator checks, and tuning limits. Run the 10,000-puzzle campaign
audit with `npm run test:progression`.

## Production preview

```sh
npm ci
npm run check
npm run build:web
npm run preview:web
```

Open http://localhost:8082. This tests the optimized bundle with deep-link fallback.
Preview storage is separate from the development server on port 8081.

## Release

Read [LAUNCH_READINESS.md](./LAUNCH_READINESS.md) before publishing.
The latest UI and interaction checks are in [FINAL_REVIEW.md](./FINAL_REVIEW.md);
the proposed free-play/cosmetic revenue model is in [MONETIZATION.md](./MONETIZATION.md).
Web, iOS, and Android are configured; store credentials and public identity are
not yet set. Copy `.env.example` to `.env.local`, enter your own values, then run
`npm run release:check`. Native release builds also run this check.

The web app includes a home-screen manifest, but does not cache the app for offline
launch. Native app assets are bundled. Completed progress is local to each device;
there is no cloud sync and unfinished attempts restart after leaving the game.

Sound effects are generated by `python3 scripts/create-sounds.py`. Launcher icons
are generated by `node scripts/create-splash.cjs`. Outfit uses the SIL Open Font
License, available in the app under Credits & licenses.

Security overrides pin `xcode` to UUID 11.1.1 and `query-string` to the patched
decode-uri-component 0.5.0. `postinstall` applies a guarded CommonJS/ESM import
adapter in query-string 7, covered by Unicode and malformed-input regression
checks. Review/remove that adapter when Expo Router upgrades this dependency.
